## Feature Highlights
- 5 physics experiments (free-fall, projectile, incline, collision, spring-mass)
- FrameCache: precomputed physics at 60fps for instant timeline scrubbing
- All modules (3D, charts, teacher, trail) read from single cache
- Binary search seek: no physics computation during drag/scrub
- Parameter changes rebuild cache, state stays in sync
- 3-mode system (Learning/Experiment/Analysis)

## S12 Performance Gains
- Scrubbing: from O(n) compute per mousemove to O(log n) binary search
- Trail: from full regeneration to cache subset sampling
- Charts: from independent derivation to shared frameCache
