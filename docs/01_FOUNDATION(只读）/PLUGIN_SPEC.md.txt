# Physics Plugin Specification

【定位修正 · 2026-08-03】

项目核心主线是：输入题目 → AI解析 → PhysicsScene → 自动生成教学动画。

实验插件体系保留，但定位修正为 **P4 扩展能力**（自定义实验、模拟器、多实验插件），不再是产品发展主线。

对插件的增量要求（兼容，不强制回溯）：

- 新增插件除物理仿真数据外，应提供教学动画所需数据：timeline phases、teacher_steps、受力可视化、公式推导（equations.derivation），使每个插件都能被教学动画引擎直接消费。
- 插件 = 实验能力的扩展点；教学动画引擎 = 核心消费方。

以下规范继续有效。
