## 1. Hammerath 风格拆解（实站证据）

| 维度 | Hammerath 做法 | 截图证据 |
|------|----------------|----------|
| 色彩 | **浅色极简**：白底、黑字、单一蓝色强调；功能卡用绿/黄/红小色点区分 | 全站 |
| 留白 | 极大留白，每个分区只做一件事，视线无干扰 | 全站 |
| 首屏结构 | 左侧：大字品牌主张「浩瀚启蒙，所想即视」+ 英文副标 "See the Unseen." + 一行定位 + **单一胶囊 CTA「开始体验 →」**；右侧：产品界面预览卡（柔和渐变 + 播放键 +「一键生成」按钮） | 首屏 |
| 功能表达 | 四张卡片，**把技术翻译成用户价值**：教学动画（Manim 动画）/ 交互式 3D（Three.js 模型）/ 智能几何（GeoGebra 绘图）/ 可视化解题（分步解析） | 功能区 |
| 流程表达 | 编号步骤 01/02/03：输入 → AI 生成 → 预览微调分享 | 功能区 |
| 输入设计 | 输入框居视觉中心，placeholder 直接给示例（"画一个三角形及其外接圆"），标注"1积分/次" | 功能区 |
| 加载/氛围 | 漂浮数学符号动画（ω ℤ ⊕ θ ∂ ∈…），轻量、有学科气质 | 加载态 |
| 信任建设 | 「教育实践」区放**真实课堂照片**——产品在真实教学场景被使用 | 应用场景区 |
| 产品形态 | Web 平台 + 桌面客户端 + API 开放平台；**按次积分制** | 导航/输入区 |

**一句话总结**：Hammerath 的风格是"克制 + 呼吸感 + 一句话说清价值"——它不炫技，所有视觉都服务于让访客 3 秒理解"输入描述，得到教学动画"。

## 2. 与本项目的对照判断

**关键前提**：Hammerath 是"营销网站 + 云平台"，我们是"桌面教学应用"。**学它的表达原则，不抄它的皮肤。**

我们当前状态（S83 后）：深色科技风（#0A0E1A）、题目输入首页、Teaching Layer 四模板——信息架构已对齐"题目驱动"，**差距在表达层的精致度与呼吸感**，不在结构。

## 3. 修改建议

### A 类：可直接落地（不触碰 FOUNDATION，建议排入 S84 或 S85 顺带）

| # | 建议 | 来源 | 落点 |
|---|------|------|------|
| A1 | **解析等待动画：漂浮物理符号**（α Ω Δ v₀ F=ma E=mc²…半透明缓慢漂浮）替代纯文字进度 | 加载态 | 首页解析中状态；克制：只在等待区，绝不进教学动画 |
| A2 | **生成进度改为编号步骤条**（01 识别实体 → 02 建立模型 → 03 编排动画），每步完成打勾 | 编号步骤 | 首页解析中状态 |
| A3 | **首页增加一句品牌副标**：主标"把不会的物理题放进来"（功能文案保留）+ 副标一句价值主张（建议："看见看不见的物理过程" / See the Unseen 的物理版） | 首屏文案 | HomePage |
| A4 | **CTA 文案精简**：「开始生成教学动画」→「一键生成」或「生成动画」 | 首屏 CTA | HomePage |

### B 类：需项目负责人决策（触及 FOUNDATION / PRD / 商业模式）

| # | 建议 | 冲突点 | 我的立场 |
|---|------|--------|----------|
| B1 | **双轨视觉策略**：桌面应用保持深色（教学场景长时间注视、3D 融合、专注力），但全面引入浅色风的"留白与呼吸感"（加大间距、减边框线、卡片化已有面板）；**未来若做营销官网/Web 版，再用 Hammerath 式浅色极简** | UI_GUIDELINES 深色背景是 FOUNDATION 只读项 | 推荐双轨，不改 FOUNDATION；营销页风格存档备用 |
| B2 | **商业模式参考积分制**：Hammerath"1积分/次"与 DD-002 云 AI 转向天然契合（云端生成按次计费是行业惯例），比订阅制门槛更低，适合学生群体 | PRD §4 订阅制（Pro ¥29/月） | 建议作为 DD-002 配套议题评估，可"订阅+积分"混合（免费额度+N 积分/次超出） |
| B3 | **「教育实践」信任区**：Hammerath 用真实课堂照片建立信任。我们还没有真实用户，但应把"真实场景验证"列为产品里程碑（找 1-2 个真实班级试用），素材反哺未来的官网/宣传 | 无冲突，属运营建议 | 记入 ROADMAP 建议 |

### C 类：明确不学（避免方向污染）

- 不把桌面首页改成营销页结构（首页是工具，不是官网）
- 不在 MVP 引入积分 UI 复杂度
- 不抄浅色皮肤到桌面应用（深色在教学场景有真实价值）
