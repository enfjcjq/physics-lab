## 3. 新发现缺陷

### P0-C：TOPIC_TO_PLUGIN 映射缺口 + 未知 topic 静默回退 free_fall（红线违背）
- 证据：T9 云端 topic=`transverse_wave` → 映射表无此键 → **静默回退加载 free_fall**，波动题显示自由落体动画；T8 电路题同理。
- 修复方向：①映射表补别名（transverse_wave/longitudinal_wave→wave，series/parallel/circuit→电路类）；②**未知 topic 禁止回退默认场景**——模糊匹配失败必须诚实报错"云端场景类型暂不支持（topic: X），请从实验库选择"；③长期方案：`buildScenePrompt` 将 topic 约束为固定枚举，从源头消除自由词。

### P0-D：降级链覆盖云端的正确拒绝（最严重，红线违背）
- 证据：B1（写诗）——云端正确判定不可生成并拒绝；降级链将其视为"云端失败"→规则解析器用关键词匹配（spring→弹簧）硬凑出**弹簧振子动画**。用户要一首诗，得到了弹簧振荡。
- B2 同源：云端拒绝（缺参数）→ 规则静默用默认参数生成（无"已使用假设 h=10"声明）。
- 修复方向：①`parseWithActive` 区分两种云端失败：**技术失败**（网络/截断/解析异常→允许降级）vs **内容拒绝**（模型返回 unsupported/无法生成→直接呈现拒绝结果，禁止降级）；②规则解析器增加非物理输入检测（物理关键词密度/必要元素缺失即拒绝）；③默认参数路径必须显示假设声明。

### P1-E（观察）：T10 复合题教学覆盖不全
- 落地反弹题只呈现下落段（free_fall），反弹与能量损失未表达——属于"近似场景"，建议在提示中明确"已简化为自由落体演示"或长期支持复合场景。
