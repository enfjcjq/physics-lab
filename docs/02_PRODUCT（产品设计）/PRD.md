## 1. 产品概述

### 1.1 产品定位

Physics Lab 是一款 **AI驱动** 的交互式物理学习平台。它不替代题库、不替代搜索引擎、不替代AI聊天——而是通过将每一道物理题自动转化为 **可观察、可操作、可实验、可探索的3D虚拟实验**，帮助学生从"记公式"彻底转变为"理解规律"。

### 1.2 产品使命

让每一道物理题都变成一个可以观察、操作、实验和探索的虚拟实验。

### 1.3 核心价值主张

**对学生：**
- 理解物理规律，而非死记硬背
- 建立物理直觉，培养科学思维
- 降低学习门槛，提升学习兴趣
- 提升解题能力，形成系统认知

**对教师：**
- 30秒自动生成课堂演示实验
- 一键生成实验案例与教学动画
- 自动生成课堂素材与扩展练习

**对学校：**
- 大幅降低实验室建设与维护成本
- 提升课堂互动性与教学效果
- 数据驱动的教学质量评估

### 1.4 核心竞争力

```
Physics Problem → PhysicsScene → Interactive Experiment → Learning System
```

- 竞争对手可复制题库、可复制AI问答
- 但难以复制：**题目→3D实验的自动生成能力**
- 护城河来源：PhysicsScene统一数据结构 + AI解析引擎 + 物理引擎 + 渲染引擎 的深度耦合

### 1.5 目标用户分层

| 阶段 | 用户群体 | 核心需求 |
|------|----------|----------|
| Phase 1 | 初高中学生 | 理解物理题目，建立直觉，整理错题 |
| Phase 2 | 物理教师 | 快速制作教学演示，生成实验案例 |
| Phase 3 | 培训机构 | 标准化教学内容，提升教学效果 |
| Phase 4 | 学校与教育局 | 区域化部署，教学质量监控 |

## 2. 功能需求

### 2.1 题目输入模块

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 文字输入 | P0 | 手动输入或粘贴物理题目文字 |
| 图片上传 | P0 | 上传题目截图，支持 JPG/PNG/WebP |
| PDF上传 | P1 | 上传试卷PDF，自动提取题目 |
| OCR识别 | P0 | 自动识别图片和PDF中的文字、公式、图形 |
| 公式编辑器 | P1 | 支持 LaTeX 公式手动编辑与修正 |
| 批量导入 | P2 | 支持多题同时导入与解析 |

### 2.2 题目解析模块

AI引擎自动从题目中提取并结构化以下信息：

| 解析维度 | 内容 |
|----------|------|
| 实体识别 | 小球、滑块、电荷、摆球、光线、弹簧、导体棒、活塞等 |
| 环境识别 | 斜面、电场、磁场、重力场、导轨、透镜、容器等 |
| 受力分析 | 重力、弹力、摩擦力、电场力、洛伦兹力、安培力等 |
| 运动识别 | 匀速、匀变速、自由落体、平抛、圆周、简谐、碰撞、波动、光学传播 |
| 约束条件 | 初始速度、初始位置、质量关系、几何约束、时间约束 |
| 目标变量 | 待求解的物理量 |

解析输出统一为 **PhysicsScene** JSON 数据结构。

### 2.3 3D交互实验模块

#### 2.3.1 视图交互

| 操作 | 描述 |
|------|------|
| 旋转 (Rotate) | 鼠标拖拽任意角度旋转场景 |
| 缩放 (Zoom) | 滚轮缩放，支持自适应视角 |
| 平移 (Pan) | 右键拖拽平移视口 |
| 拖拽 (Drag) | 拖拽物体调整初始位置/状态 |
| 重置 (Reset) | 一键恢复默认视角和初始状态 |
| 重播 (Replay) | 重播当前实验动画 |

#### 2.3.2 场景要素

每个3D实验必须包含：

- 三维坐标系（刻度标注）
- 发光运动轨迹
- 动态受力箭头（大小/方向随运动变化）
- 物体模型（基础几何体 + 可选材质）
- 环境可视化（斜面颜色、场线、轨道等）

#### 2.3.3 物理领域覆盖

| 领域 | MVP覆盖 | 完整覆盖 |
|------|---------|----------|
| 力学 | ✅ | ✅ |
| 运动学 | ✅ | ✅ |
| 电磁学 | 基础 | ✅ |
| 光学 | — | ✅ |
| 热学 | — | ✅ |
| 波动 | 基础 | ✅ |
| 近代物理 | — | ✅ |

### 2.4 参数调节模块

用户可实时调节物理参数，实验即时响应：

| 参数类别 | 可调参数 |
|----------|----------|
| 力学参数 | 质量、初速度、角度、摩擦系数、弹性系数 |
| 空间参数 | 长度、高度、半径、距离 |
| 时间参数 | 模拟时长、时间缩放 |
| 电磁参数 | 电荷量、电压、电流、电阻、磁感应强度、电场强度 |

### 2.5 数据展示模块

实时图表展示物理量变化：

| 图表类型 | 内容 |
|----------|------|
| 位移-时间曲线 | s-t 图 |
| 速度-时间曲线 | v-t 图 |
| 加速度-时间曲线 | a-t 图 |
| 能量曲线 | 动能、势能、机械能随时间变化 |
| 受力曲线 | 各分力随时间变化 |
| 自定义图表 | 用户选择任意物理量绘制 |

### 2.6 AI模式

| 模式 | 描述 | MVP |
|------|------|-----|
| 快速解题 | 给出解题步骤和最终答案 | ✅ |
| 详细解析 | 逐步分析受力、运动、能量，完整推导 | ✅ |
| AI教师 | 对话式引导，纠正错误思路，建立物理直觉 | Phase 2 |
| 苏格拉底教学 | 纯提问式引导，不直接给答案，引导学生自主发现规律 | Phase 2 |

### 2.7 学习系统

#### 2.7.1 错题本

- 自动收录解析失败或用户标记的题目
- 支持标签分类（力学/电磁学/光学等）
- 支持按知识点、难度、时间筛选
- 支持错题重做与对比

#### 2.7.2 收藏夹

- 用户手动收藏感兴趣的实验
- 支持分类文件夹管理
- 支持排序（时间/名称/学科）

#### 2.7.3 学习记录

- 自动记录每道题的解析和实验历史
- 记录用户调节过的参数
- 记录实验操作行为（旋转/缩放/拖拽等）

#### 2.7.4 知识图谱

- 自动关联相关知识点
- 可视化展示知识结构
- 标注薄弱环节

#### 2.7.5 学习路径

- 基于知识图谱的个性化学习路径推荐
- 自适应难度调整
- 阶段性学习报告

### 2.8 教学动画模块

基于 Manim 引擎自动生成教学动画：

| 动画类型 | 内容 |
|----------|------|
| 受力分析动画 | 逐步展示各力的大小和方向变化 |
| 能量分析动画 | 动能、势能相互转化的可视化 |
| 公式推导动画 | 从已知公式到目标公式的逐步推导 |
| 运动轨迹动画 | 轨迹的逐帧绘制与对比 |
| 多镜头动画 | 不同视角、不同阶段的切换展示 |

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 要求 |
|------|------|
| 题目解析耗时 | MVP阶段 ≤ 30秒；优化后 ≤ 10秒 |
| 3D场景首帧渲染 | ≤ 2秒 |
| 参数调节响应 | ≤ 100ms（实时反馈） |
| 应用启动时间 | ≤ 3秒 |
| 内存占用 | 空闲 ≤ 300MB；运行时 ≤ 1GB |
| 磁盘占用 | 基础安装 ≤ 500MB |

### 3.2 离线要求

- 核心功能（题目解析、3D实验、错题本、收藏夹）**完全离线可用**
- AI解析使用本地模型（Ollama + Qwen/DeepSeek）
- 首次启动无需登录
- 云同步为可选功能

### 3.3 平台要求

| 平台 | MVP | 后续 |
|------|-----|------|
| Windows 10/11 | ✅ | ✅ |
| macOS | — | Phase 5 |
| Linux | — | Phase 5 |

### 3.4 安全性

- 用户数据本地存储（SQLite 加密）
- 不上传用户题目数据
- 云同步使用端到端加密
- 本地AI模型完整性校验

### 3.5 可维护性

- Monorepo 架构，模块独立
- 统一的 PhysicsScene 接口隔离各层
- 完整的单元测试和集成测试
- 自动化 CI/CD 流水线

### 3.6 国际化

| 语言 | MVP | 后续 |
|------|-----|------|
| 简体中文 | ✅ | ✅ |
| 英文 | — | Phase 3 |
| 繁体中文 | — | Phase 3 |

## 5. 用户旅程

### 5.1 核心用户旅程（学生）

```
打开应用 → 输入题目（文字/图片/PDF）
→ AI自动解析（<30s）
→ 生成PhysicsScene
→ 展示3D互动实验
→ 用户旋转/缩放/拖拽观察
→ 调节参数（质量/速度/角度等）
→ 查看数据曲线变化
→ 选择AI模式（快速解题/详细解析）
→ 查看知识点分析
→ 收藏或加入错题本
→ 查看相关知识图谱
→ 获取推荐练习
```

### 5.2 教师用户旅程

```
打开应用 → 输入教学题目
→ AI自动生成实验和动画
→ 调整参数与视角到最佳展示状态
→ 导出为课堂演示素材
→ 生成配套练习题
→ 分享给学生
```

## 7. 风险与约束

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| AI解析准确率不足 | 用户体验差 | 持续优化Prompt，收集反馈数据微调模型 |
| 本地模型过大 | 安装包过大 | 按需下载模型，渐进式加载 |
| 3D性能不足 | 低配电脑卡顿 | LOD策略，降级渲染模式 |
| OCR识别错误 | 解析失败 | 支持手动修正，多模态交叉验证 |

### 7.2 商业风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 大厂入场竞争 | 市场份额 | 深耕物理垂直领域，建立数据壁垒 |
| 用户付费意愿低 | 收入不足 | 先做口碑再做变现，教育版B端收入优先 |
| AI监管政策变化 | 合规风险 | 本地化部署，不依赖云端AI |

### 7.3 约束条件

- 必须支持 Windows 10/11 离线运行
- 首版安装包 ≤ 500MB
- 核心技术栈不可变更（Electron/React/Three.js/SQLite）
- PhysicsScene 作为所有模块间的唯一数据接口
