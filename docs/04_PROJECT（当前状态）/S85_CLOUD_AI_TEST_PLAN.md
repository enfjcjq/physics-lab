## 1. 目的

验证"任意题目 → 正确教学动画"核心承诺在云 AI 路径下是否成立。三个维度：**云端真的在用**（不静默降级）、**生成的动画物理正确**（教学红线）、**失败时诚实**（不硬凑）。

## 2. 鉴别原则（重要）

每题必须记录**生成来源**：
- 云端调用的直接证据：网络面板出现 `POST api.deepseek.com/chat/completions`；
- 鉴别题设计：测试集中包含规则解析器**不支持**的题型——若这些题生成了动画，证明走了云端；若显示诚实失败，说明云端未被调用（配置仍有问题）；
- 若云端失败静默降级到规则解析 → 记为缺陷（违反诚实原则，见留言 28 P0-1）。

## 3. 测试集（10 题，中英混合，真实作业难度）

| # | 题目 | 期望场景 | 关键参数校验 | 规则解析器可否处理 |
|---|------|----------|--------------|--------------------|
| T1 | 一个小球从 10 m 高处由静止自由落下，求落地速度 | 自由落体 | h=10, g=9.8 | 可（基线对照） |
| T2 | 以 20 m/s 水平抛出小球，抛出点高 45 m，求射程 | 平抛 | v=20, h=45 | 可 |
| T3 | 质量 2 kg 的滑块沿 30° 光滑斜面下滑，求加速度 | 斜面 | m=2, θ=30, μ=0 | 可 |
| T4 | A car at 20 m/s brakes with deceleration 5 m/s², find braking distance | 匀减速直线运动 | v=20, a=-5 | **不可（鉴别题）** |
| T5 | 质量 0.5 kg 的小球挂在劲度系数 50 N/m 的弹簧上振动，求周期 | 弹簧振动 | m=0.5, k=50 | 可 |
| T6 | 两球弹性碰撞：m1=2 kg 以 3 m/s 撞击静止的 m2=1 kg，求碰后速度 | 碰撞 | m1=2,v1=3,m2=1 | 可 |
| T7 | 一个 12 V 电源接 4 Ω 电阻，求电流 | 欧姆定律 | V=12, R=4 | 可 |
| T8 | R1=6 Ω 与 R2=3 Ω 并联接在 12 V 电源上，求总电流 | 串并联电路 | R1=6,R2=3,V=12 | 弱（半鉴别） |
| T9 | 一列波频率 2 Hz、波长 0.5 m，求波速 | 波动 | f=2, λ=0.5 | 可 |
| T10 | 中文综合题：小球从 5 m 高自由落下，落地后反弹到 3 m，求落地速度和能量损失 | 自由落体+碰撞复合 | h=5, 反弹 h=3 | **不可（鉴别题）** |

## 4. 边界题（3 道，验证诚实红线）

| # | 题目 | 期望行为 |
|---|------|----------|
| B1 | "请写一首关于春天的诗"（非物理题） | 明确诚实拒绝，不生成动画 |
| B2 | "一个球从高处落下，求速度"（缺数值） | 合理默认+明确声明所用假设，或提示补充；不得静默编造 |
| B3 | 大学物理题（如"求氢原子基态能量"） | 诚实拒绝或正确生成；**禁止错误动画** |

## 5. 记录表（每题填写）

| 字段 | 说明 |
|------|------|
| 云端调用 | 是否观察到 /chat/completions 请求（Y/N） |
| 生成来源 | cloud / rule / 失败 |
| 场景正确 | 场景类型是否符合题意（Y/N） |
| 参数正确 | 提取数值与题目一致（Y/N，列出差错） |
| 动画可播 | 完整播放无卡死（Y/N） |
| 教学脚本 | PhaseCard/公式/标注非空且与题目相关（Y/N） |
| 耗时 | 从点击到动画就绪的秒数 |

## 6. 通过标准

| 指标 | 标准 |
|------|------|
| 云端调用率 | 配置正确时 10/10 题观察到云端请求（否则配置缺陷未修复） |
| 云端生成成功率 | ≥ 8/10（允许 2 题因题型超范围诚实失败） |
| 物理正确红线 | **0 题错误动画**——宁可诚实失败，不得生成与题意矛盾的场景（一票否决） |
| 参数提取准确率 | ≥ 8/10 数值正确 |
| 平均生成耗时 | ≤ 30 s |
| 边界题 | B1 必须拒绝；B3 不得生成错误动画；B2 不得静默编造 |

## 7. 体验验收（设计侧走查项）

1. 生成等待期：漂浮符号等待动画 + 编号步骤进度可见，无"卡死感"；
2. 云端失败时：提示**明确告知走了降级**（当前实现为静默降级——缺陷，见留言 28 P0-1，修复前此条预期不通过，如实记录）；
3. 生成成功后：自动进入讲解节奏首播（phase 减速+停顿生效）；
4. 诚实失败画面：文案可行动（给出替代建议），有"使用示例场景继续"逃生口。
