## 2026-08-03 · DD-001 · 首次体验审计与四项设计提案

**背景**：项目于 2026-08-03 重新定位为 Physics AI Engine（输入题目 → AI 自动生成教学动画）。产品体验与视觉设计 Agent 对当前产品（V4.6 / S69）进行首次审计。

**核心判断**：当前 UI 为"实验驱动"架构（首屏=实验模拟器+实验切换器），与新定位的"题目驱动"核心主线错位。PhysicsScene 数据结构（phases / teacher_steps / equations / camera_script）已具备教学叙事能力，瓶颈在呈现层设计而非技术。

**提出的长期设计方向**（待项目负责人批准）：

1. **题目优先的信息架构**：题目输入应成为启动首页，实验库降级为二级入口。核心闭环必须在 UI 第一路径上可被感知。
2. **Hybrid 2D+3D 的呈现定义**：3D 画布负责空间结构；2D 图层（HTML/SVG，Timeline 驱动）负责阶段卡、受力标注、公式推导。信息必须出现在"它解释的物体旁边"，而不是分离的侧面板。低性能场景降级为面板联动。
3. **渐进式复杂度**：默认界面极简（画布+Timeline+讲解入口），高级能力按需展开；不做功能堆砌。
4. **教学语义色表**：颜色是教学语言（红=力、青=速度、琥珀=能量、橙=关键事件），全项目统一，跨实验形成稳定视觉直觉。

**详细方案**：见 `docs/02_PRODUCT（产品设计）/UX_AUDIT_AI_ENGINE.md`

**状态**：提案待批准。批准后此条目更新为"已采纳"并记录实施结果。
