## Key Architecture
- AIProvider interface with RuleParser + OllamaProvider backends
- Swap between local Ollama / OpenAI / Claude without changing business logic
- PhysicsScene-driven: all modules read from PhysicsScene, not raw problem text
- Plugin system: add new experiment = add new plugin, no UI changes needed
- 6 plugins, 409 en-US / 564 zh-CN i18n keys
- 3 modes: Learning / Experiment / Analysis
