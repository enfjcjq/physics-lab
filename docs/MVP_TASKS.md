---

## 1. 总体策略

### 1.1 MVP 目标

验证核心价值主张：**物理题目 → PhysicsScene → 3D交互实验** 闭环的可行性和用户价值。

### 1.2 MVP 不做的事

| 不做 | 理由 |
|------|------|
| 用户登录/注册系统 | 默认本地用户，Phase 5再做 |
| 云同步 | Phase 5 |
| AI教师/苏格拉底模式 | Phase 2 |
| 知识图谱可视化 | Phase 3 |
| Manim动画生成 | Phase 2 |
| macOS/Linux 打包 | Phase 5 |
| 国际化 | 仅中文 |
| 付费系统 | Phase 5 |

### 1.3 任务分类

| 分类 | 说明 |
|------|------|
| **INFRA** | 基础设施搭建 |
| **CORE** | 核心业务逻辑 |
| **UI** | 用户界面 |
| **AI** | AI引擎相关 |
| **INTEG** | 集成与联调 |
| **QA** | 测试与质量保证 |

### 1.4 优先级标记

| 标记 | 说明 |
|------|------|
| P0 | 阻塞项，必须最先完成 |
| P1 | 核心功能，MVP必须交付 |
| P2 | 重要但可降级，MVP尽量交付 |
| P3 | 锦上添花，MVP可延后 |

## 4. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| AI解析准确率不达标 | 高 | 严重 | T310提前建立测试集，迭代优化Prompt；T604支持手动修正 |
