## 0. 一句话定位

**会运动的物理示意图**：扁平、矢量、几何、极简；每个元素必须回答"它帮助学生理解了什么"，答不上来就删掉。

## 1. 坐标与视口（对齐 scene2d-data.ts）

| 项 | 规格 |
|----|------|
| 投影 | 世界坐标 → 视口坐标：等比缩放、y 轴翻转、完整场景 fitToViewport |
| 留白 | 视口四周 padding **8%**（bounds 外扩），任何元素不得贴边 |
| 背景 | 深色 `#0A0E1A`（延续 B1 双轨），纯色无渐变 |
| 画布基准 | 矢量坐标用 SVG viewBox 逻辑坐标，1 unit = 1px @基准 1200×675（16:9），渲染层负责实际缩放 |

## 2. 矢量元素体系（E1-E11，完整词汇表）

> 线宽/字号均为 viewBox 逻辑单位。五色语义：力 `#EF4444` / 速度 `#00D4FF` / 能量 `#F59E0B` / 关键事件 `#FF6B00` / 中性 slate 系（`#334155` 结构 / `#94A3B8` 次级 / `#E2E8F0` 强调）。

### E1 实体（Entity）
| 实体 | 图形 | 规格 |
|------|------|------|
| 小球 | 圆 | 半径 14，描边 `#E2E8F0` 2px，填充 `#334155`（实心，无光影） |
| 滑块 | 矩形 | 36×24 圆角 4，同上描边/填充 |
| 斜面 | 直角三角形 | 描边 `#94A3B8` 2px，填充 `#1E293B`（比背景亮一档） |
| 弹簧 | 折线（锯齿） | 6 段，描边 `#94A3B8` 2px |
| 导线/轨道 | 线段 | 描边 `#94A3B8` 2.5px |
| 地面 | 水平线 + 斜线纹理 | 主线 `#94A3B8` 2.5px；下方 45° 短斜线（长 8、间距 10、透明度 40%） |

- 实体不做拟真渲染：无渐变、无阴影、无高光；选中/讲解强调用描边变 `#E2E8F0` 加粗至 3px（时长 250ms）。

### E2 轨迹线（Trajectory）
- **已走过**：实线，`#00D4FF` 40% 透明度，线宽 2；只保留最近 3 秒内的轨迹（更早的淡出消失，exit 200ms）；
- **预测轨迹**（仅 phase 开始时短暂显示 800ms 后淡出）：虚线 dash 6/6，`#94A3B8` 60%。

### E3 速度矢量
- 颜色 `#00D4FF`，线宽 **2.5**，箭头头部：长 10、宽 8 的实心三角；
- 长度：**矢量比例尺**（见 §3.1）；
- 标签：符号 `v`（斜体，#00D4FF，14px），锚点在箭头尖端外 6px；
- 锚定实体质心，随实体移动，长度随速度实时变化（每帧更新，无独立动画）。

### E4 力矢量
- 颜色 `#EF4444`，线宽 2.5，头部同 E3；标签 `G`/`N`/`f`/`T`（正体，14px）；
- 多个力同时显示时允许共线叠加偏移（垂直于矢量方向偏 10px 避免遮挡）；
- 平衡力系（教学需要时）：等长反向双箭头 + 中点小圆点标记。

### E5 加速度矢量
- 颜色 `#EF4444`，线宽 2，**虚线** dash 4/4（与力矢量的区别：虚线 + 无粗细强调）；标签 `a`（斜体）。

### E6 辅助线（全部虚线，`#94A3B8` 50%，线宽 1.5）
- 高度标记：垂直虚线 + 两端短横（长 8）+ 数值标签（12px，`#94A3B8`）；
- 位移标记：水平/路径虚线 + 端点箭头 + `s` 标签；
- 角度弧：半径 28 的圆弧 + 度数标签（12px）。

### E7 文字标注
- 物理量符号优先于文字说明；标签字号三级：实体标注 14px / 数值标注 12px / 说明文字 12px（每屏说明文字 ≤ 2 处，每处 ≤ 20 字）；
- 颜色跟随所属元素色；无所属用 `#94A3B8`。

### E8 能量条（EnergyBar）
- 位置：画布右上角固定，两根并列（动能 KE `#F59E0B` 实心 / 势能 PE `#F59E0B` 60% 透明），宽 14，高 ∝ 数值（比例尺固定），底部对齐；
- 标签 KE/PE（12px）在条下方；总能量恒定时顶部画一条细横线（`#94A3B8`）标示守恒；
- 高度变化：逐帧跟随（无缓动），守恒线静态。

### E9 事件脉冲（EventPulse 2D 版）
- 事件点同心圆扩散：内圆 r=10 `#FF6B00` 实心 + 外扩圆环（r 10→40，透明度 100%→0，400ms）；
- 事件后静止帧 300ms（R4 已有机制沿用）。

### E10 网格（可选，默认关）
- 间距 = 世界坐标 1m 的投影长度，`#334155` 30%；仅在参数面板开启时显示。

### E11 教学模板（沿用四模板，2D 原生表达）
- PhaseCard：画布左上，规格沿用 TEACHING_LAYER_SPEC；
- FormulaStrip：画布底部居中，沿用（含 beautifyFormula 记号渲染）；
- ForceCallout：在 E4 力矢量旁的短标注（"重力 G = mg"），沿用模板样式；
- EventPulse：E9。

## 3. 图解约定（物理量的图形语法）

### 3.1 矢量比例尺
- 同一场景同一矢量类型用**统一比例尺**：速度 1 m/s = 32px（矢量长 ≤ 160px 封顶，避免出画）；力 1 N = 6px（独立比例，同样封顶）；
- 比例尺**不显示在画面上**（保持极简），但必须全程一致——学生通过"箭头变长"直觉感知"速度变大"。

### 3.2 出现与消失
- 矢量首次出现：从长度 0 生长到目标值（300ms，ease-standard）+ 透明度 0→100%（250ms）；
- 消失：透明度 100%→0（200ms），禁止瞬间消失；
- 元素出现时机由教学脚本（TeachingScript / overlay_hints）驱动，禁止无故闪烁。

### 3.3 数值标注节奏
- 常态只显示符号（`v`）；数值（`v = 14.0 m/s`）只在：①关键事件静止帧、②phase 结尾停顿、③用户悬停矢量时显示。

### 3.4 阶段切换
- phase 切换时：上一阶段专属辅助线淡出（200ms）、新阶段元素淡入（250ms）；实体与轨迹**不消失**（连续性）。

## 4. 3D→2D 视角锁定视觉契约（S88-C 预留，本 Sprint 只定义契约不实现）

1. **空间对应**：锁定视角后，2D 图解中实体的屏幕位置 = 3D 末帧该实体屏幕位置（偏差 < 5% 视口尺寸）；2D 场景的 world bounds 由锁定投影下的可见实体包围盒决定；
2. **过渡（600-800ms，可逆）**：光照淡出 → 材质压平为纯色 → 描边浮现 → 辅助元素渐入，四段各约 150-200ms，可中断可回退；
3. **返回 3D**：相机状态（位置/朝向/fov）完整保留，逆过渡；
4. **数据契约**：2D 渲染层接收的世界坐标 = 3D 场景实体在锁定投影平面上的投影坐标（工程在 S88-C 实现投影计算；S88-A 阶段平面问题直接用世界 xy 坐标）。

## 5. 动效与降级

- 沿用 S86 token：`--dur-enter 250ms` / `--dur-exit 200ms` / `--ease-standard cubic-bezier(0.4, 0, 0.2, 1)`；
- 矢量生长/能量条平滑跟随不套缓动（物理量必须诚实反映 f(t)）；
- `prefers-reduced-motion`：所有出现/消失/生长动画降级为直接显示（轨迹仍保留静态显示）。

## 6. S88-A 自由落体纵切验收清单

1. 释放/自由下落/落地三阶段完整呈现：球（E1）、高度虚线（E6）、G 力（E4）、v 速度矢量生长（E3）、轨迹线（E2）、能量条 PE↓KE↑（E8）、落地脉冲+静止帧（E9）；
2. **确定性**：Timeline 拖到任意时刻，画面逐元素一致（state=f(t) 红线）；
3. 五色语义、深色背景、padding 8% 内全元素入画（h=10 完整路径 0→10m）；
4. 默认 0.8x + 首播讲解节奏（R1/R2）在 2D 视图同样生效；
5. 无：渐变、阴影、拟真材质、PPT 转场、无故闪烁。

## 7. 禁区重申

卡通/Q 版/角色/影视/写实 3D/游戏视觉/PPT 模板/大量 UI 装饰/大量渐变光影——全部禁止。丰富度只能来自运动、空间、节奏和信息层级。
